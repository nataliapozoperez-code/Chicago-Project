Chicago: La película y el musical

Descripción del proyecto

Este proyecto consiste en la creación de una página web sobre *Chicago*, el musical y su adaptación cinematográfica de 2002. La página incluye información sobre el origen de la obra, la película, sus personajes y las canciones del musical. El objetivo es presentar la información de forma organizada y atractiva utilizando HTML y CSS, aplicando los conocimientos aprendidos en clase.

Empezando

Para visualizar el proyecto, es necesario descargar los archivos y abrir la página web en un navegador.

Requisitos previos

Un navegador web, como Google Chrome, Firefox o Microsoft Edge.
Un editor de código, como visualcodestudio
Los archivos HTML y CSS del proyecto.

Instalación

1. Descarga o copia los archivos del proyecto en una carpeta de tu ordenador.
2. Comprueba que los archivos HTML y CSS están en la misma carpeta o en las rutas correspondientes.
3. Abre la carpeta con Visual Studio Code.
4. Busca el archivo index.html.
5. Abre el archivo con tu navegador para visualizar la página web.

No es necesario instalar dependencias adicionales para ejecutar la página.

Ejecutando las pruebas

Para comprobar que el proyecto funciona correctamente, abre la página en un navegador y revisa sus diferentes apartados.

Pruebas de funcionamiento

Comprobar que la página se abre correctamente.
Verificar que aparecen todos los títulos, textos e imágenes.
Revisar que los enlaces de navegación funcionan.
Comprobar que las canciones y los demás contenidos se muestran correctamente.
Verificar que la página se adapta a diferentes tamaños de pantalla.

Prueba de estilo

Se debe comprobar que el diseño CSS se aplica correctamente y que la página mantiene una apariencia uniforme.

Los colores y las tipografías deben ser coherentes con la temática de Chicago.
Los textos deben ser legibles.
Las imágenes deben mostrarse correctamente.
La distribución debe ser ordenada tanto en ordenador como en dispositivos móviles.

Despliegue

La página puede visualizarse de forma local abriendo el archivo index.html en un navegador. Si se desea publicar en Internet, se pueden utilizar servicios de alojamiento de páginas estáticas, como GitHub Pages.
